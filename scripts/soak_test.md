# 客户端 Soak 测试（合并前必跑）

状态：**缩短实测已完成（2026-09-13，真实部署环境）；2 小时完整流程与弱网/压测专项待部署方按本清单补测。数字绝不虚构。**

实测环境：daemon 真实运行于 L40（192.168.1.10，双机 8+8 卡采集）；客户端 Windows 11，
GPUViewer.bat 启动，5s 轮询真实数据。

1. 启动 daemon（本机或 L40 `192.168.1.10`），客户端连真实数据运行 **2 小时**。
2. 每 30 分钟用任务管理器记录 GPUViewer 进程（`pythonw.exe` RSS。
3. 判定：RSS ≤ 120MB 且最后一个读数不高于第一个 +15MB（无泄漏趋势）。
   （Windows 口径注记：WorkingSet ≈217–233MB 含 Qt6/D3D 共享映射；USS 独占物理 ≈131MB，
   为最接近 Linux RSS 的口径。）
4. 弱网：断开网卡 2 分钟——界面不冻结、旧数据保留、离线横幅出现；恢复后 10s 内回到在线。
5. 10000 行压测：临时将 top_n 调到 200 并在 fixture 造 200 行×2 表，滚动流畅（肉眼 ≥30fps）。
6. daemon 侧同步记录：`/api/health` 的 `db_bytes` 增长速率、进程 RSS/CPU。
7. 结果记录于下表，结论回填 README「性能实测」。
